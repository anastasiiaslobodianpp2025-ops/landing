# FeelUp

Адаптивний лендинг безкоштовної анонімної платформи психологічної самодопомоги: користувач обирає настрій і отримує коротку дихальну вправу або аудіо-релакс.

## Демо
- GitHub Pages: [посилання]
- Netlify: [посилання]

## Стек
HTML5, Tailwind CSS (CDN), мінімальний JavaScript, custom-styles.css

## Структура
index.html, custom-styles.css, assets/ (images, icons, fonts)

## Запуск локально
Відкрийте index.html у браузері або запустіть Live Server у VS Code.

## Важливо
Платформа не замінює очну медичну допомогу. Номери гарячих ліній наведено у футері сайту.
